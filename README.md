# Drago — Official Releases

This repository publishes **signed release builds** of Drago, a private,
voice-first personal AI assistant for Android. It holds compiled app
packages only — Drago's source code lives in a separate, private
repository. Nothing here is hand-edited; every file is regenerated by CI
on each release.

## Installing

1. Download the APK above.
2. Android will ask you to allow installs from this source the first time — expected for any app installed outside the Play Store. Allow it, then continue.
3. Open the downloaded file to install.
4. After that, Drago checks for new versions automatically every time you open it. You won't need to come back here again unless reinstalling from scratch.

## Verifying your download (optional)

Every release lists a SHA-256 checksum above and in `version.json`. To confirm your download matches exactly what CI built:

```
sha256sum Drago-v12.apk
```

Beyond that, Android itself refuses to install an update unless it's signed with the same certificate as your current install — a hard OS-level guarantee that only the real developer's signing key can ever produce something Android accepts as an update to Drago.

## Why the checks here don't need a login

Drago's in-app update check reads `version.json` in this repo with a plain, unauthenticated request. That only works because this repo — unlike Drago's source — is public: no personal access token, no GitHub account, no setup required for anyone who installs the app.

## Privacy

Drago has no backend server. It runs entirely on your device and talks directly to the AI provider you configure with your own API key. This repository, and the app itself, send nothing to us.
